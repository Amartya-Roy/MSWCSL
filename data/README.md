# data/

Simulation draws and dataset acquisition instructions.

Summary CSVs and JSONs (`cells.csv`, `summary.json`, `paired.csv`,
`matched.csv`) are included directly 

## Acquiring real benchmark datasets

Set `MSWCSL_DATA_ROOT=/path/to/mswcsl_data` and arrange the files as:

```
mswcsl_data/
├── fmri/smith2011/      NetSim .mat files — https://www.fmrib.ox.ac.uk/datasets/netsim/
├── dream3/yeast/        DREAM3 gold standard + trajectories — https://www.synapse.org/Synapse:syn2787209
└── finance/20-1A/ 20-1B/  Proprietary series — contact authors
```

`Syn-6` and CauseMe VAR(5) draws are generated by the run scripts
(no download needed).
